Samsung fornuizen en inbouwovens foutcodes

Samsung-fornuizen tonen een tweedelige code (E-08, E-0A, E-27) voor de oven en korte codes (SE, tE, LE) voor het bedieningspaneel. Meestal is het een sensor, het deurslot of een vastzittende toets.

Het opgeslagen foutlogboek uitlezen

Samsung-ovens hebben geen voor de gebruiker toegankelijk foutenlogboek. De code blijft op het display staan totdat u de oorzaak verhelpt of de stroom 3 minuten uitschakelt in de zekeringenkast; als de code na een reset terugkomt, moet u hem als een echte storing beschouwen.

Servicemenu's zijn bedoeld voor monteurs. Het uitlezen van het logboek is onschadelijk; wijzig geen kalibratiewaarden.
